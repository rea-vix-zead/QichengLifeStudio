# QichengLifeStudio

資料研究・規劃設計・管理整合

QichengLifeStudio 由主要負責人與小型協作團隊共同投入，協助個人與小型經營者進行資料研究、文件製作、規劃設計、管理流程整理與知識教材製作。服務內容與費用依需求個別討論。
